# 组合数学与模运算求解器高阶 Prompt

## 可直接复制给 AI 的 Prompt

你是一个严格的 Python 算法函数生成器。你的任务是编写一个名为 `solve(n, k, m)` 的函数，计算如下组合数学结果：

1. 先计算将 `n` 个相同物品划分为 `k` 个非空组的方案数。
   - 组之间不区分顺序。
   - 每个组至少包含 1 个物品。
   - 这等价于整数 `n` 划分为恰好 `k` 个正整数部分的方案数。
2. 再将上述方案数乘以 `m` 个不同物品的全排列数 `m!`。
3. 最终结果对 `10^9 + 7` 取模。

强制算法要求：
- 使用 `MOD = 10**9 + 7`。
- 必须在动态规划的每一次加法状态转移后立即取模。
- 必须在阶乘的每一次乘法后立即取模。
- 必须使用空间优化的一维动态规划，空间复杂度应为 `O(n)` 或 `O(n - k)`。
- 时间复杂度应为 `O(n * k + m)`。
- 需要正确处理边界：`k > n` 时返回 0；`k == n` 时划分方案数为 1。

推荐思路：
- 将每个非空组先放入 1 个物品，剩余 `n - k` 个相同物品允许放入最多 `k` 个组。
- 因此问题转化为：计算整数 `n - k` 被划分为不超过 `k` 个部分的方案数。
- 根据整数划分的共轭性质，这等价于用不超过 `k` 的部件大小组成 `n - k` 的方案数。
- 可用一维完全背包式 DP：
  - `dp[0] = 1`
  - 对 `part` 从 1 到 `k`
  - 对 `total` 从 `part` 到 `n - k`
  - 执行 `dp[total] = (dp[total] + dp[total - part]) % MOD`

输出要求：
- 只能输出一个 Python 函数定义。
- 函数名必须是 `solve(n, k, m)`。
- 不要输出 Markdown 代码围栏。
- 不要输出解释、示例、测试代码或任何多余文本。
- 可以在函数内部定义常量和局部变量。
- 不需要也不要写 `input()`、`print()` 或命令行入口。

期望输出形态：
```text
def solve(n, k, m):
    ...
```

## 5 道练习题与答案

### 练习 1

输入：
```text
n = 5, k = 2, m = 3
```

计算：
- 5 划分为 2 个非空组：1+4、2+3，共 2 种
- 3! = 6
- 答案：2 * 6 = 12

答案：
```text
12
```
