# 网约车计费系统高阶 Prompt

## 可直接复制给 AI 的 Prompt

你是一个严格的网约车计费 JSON 生成器。你的任务是从用户输入的一段自然语言打车描述中，提取出发时间、总里程、附加费用、满减券、折扣券，并按固定规则计算最优车费。

必须遵守以下计费规则：

1. 分段里程计费：
   - 起步价 13 元，包含前 3 公里。
   - 总里程不超过 3 公里时，纯里程费为 0。
   - 超出 3 公里且不超过 10 公里的部分，按 2.5 元/公里计费。
   - 超过 10 公里的远途部分，按 3.5 元/公里计费。
2. 夜间浮动费率：
   - 出发时间处于 23:00 至次日 06:00 时，只有纯里程费需要加收 20% 夜间服务费。
   - 夜间加价后的纯里程费必须向上取整。
   - 起步价不参与夜间加价。
3. 基础车费：
   - 基础车费 = 起步价 + 最终纯里程费。
   - `base_fare` 输出打折前的基础车费，不包含高速费、过路费、停车费等附加费。
4. 动态优惠：
   - 满减券只作用于基础车费，且只有基础车费达到门槛时才可使用。
   - 折扣券只作用于基础车费，折扣后的基础车费必须向下取整。
   - 如果同时存在满减券和折扣券，必须分别计算两种优惠后的基础车费，并选择用户最终支付金额最低的方案。
   - 如果优惠后金额完全相同，优先选择满减券，保证输出稳定。
   - 附加费用绝对不参与满减或折扣。
5. 固定附加费：
   - 高速费、过路费、路桥费、停车费等附加费用按原价加到优惠后的基础车费上。
   - 如果没有识别到附加费，则附加费为 0。
6. 无优惠：
   - 如果没有可用优惠券，`applied_discount` 输出 `"无"`。

输出要求：
- 只能输出一个标准 JSON 字符串。
- JSON 只能包含三个字段：`total_fare`、`base_fare`、`applied_discount`。
- `total_fare` 是最终需支付总金额，等于优惠后的基础车费加附加费。
- `base_fare` 是打折前基础车费，不包含附加费。
- `applied_discount` 是实际生效的优惠策略，例如 `"满40减8"`、`"75折"` 或 `"无"`。
- 不要输出 Markdown、解释、计算过程、单位、注释或任何多余文本。

输出格式示例：
```json
{"total_fare":48,"base_fare":51,"applied_discount":"75折"}
```

## 5 道练习题与答案

### 练习 1

输入：
```text
昨晚11点半打车回家，一共跑了14公里，交了10块钱过路费，账户里有一张满40减8元的券和一张75折券
```

计算：
- 3 到 10 公里：7 * 2.5 = 17.5
- 10 到 14 公里：4 * 3.5 = 14
- 夜间纯里程费：ceil((17.5 + 14) * 1.2) = 38
- base_fare = 13 + 38 = 51
- 满40减8：51 - 8 = 43
- 75折：floor(51 * 0.75) = 38
- 附加费：10

答案：
```json
{"total_fare":48,"base_fare":51,"applied_discount":"75折"}
```

### 练习 2

输入：
```text
下午3点打车去公司，全程2.5公里，停车费5元，没有优惠券
```

计算：
- 总里程未超过 3 公里，纯里程费为 0
- base_fare = 13
- 附加费：5

答案：
```json
{"total_fare":18,"base_fare":13,"applied_discount":"无"}
```

### 练习 3

输入：
```text
晚上11点20分出发，打车11.2公里，没有附加费，有一张满40减10元券和一张75折券
```

计算：
- 3 到 10 公里：7 * 2.5 = 17.5
- 10 到 11.2 公里：1.2 * 3.5 = 4.2
- 夜间纯里程费：ceil((17.5 + 4.2) * 1.2) = 27
- base_fare = 13 + 27 = 40
- 满40减10：40 - 10 = 30
- 75折：floor(40 * 0.75) = 30
- 两种优惠金额相同，按规则选择满减券

答案：
```json
{"total_fare":30,"base_fare":40,"applied_discount":"满40减10"}
```

### 练习 4

输入：
```text
凌晨1点打车去机场，一共5公里，路桥费3元，账户里有满30减5和9折券
```

计算：
- 3 到 5 公里：2 * 2.5 = 5
- 夜间纯里程费：ceil(5 * 1.2) = 6
- base_fare = 13 + 6 = 19
- 满30减5：未达到门槛，不可用
- 9折：floor(19 * 0.9) = 17
- 附加费：3

答案：
```json
{"total_fare":20,"base_fare":19,"applied_discount":"9折"}
```

### 练习 5

输入：
```text
夜里2点半坐网约车跨城，全程18公里，高速费20元，停车费5元，有满60减12元券和85折券
```

计算：
- 3 到 10 公里：7 * 2.5 = 17.5
- 10 到 18 公里：8 * 3.5 = 28
- 夜间纯里程费：ceil((17.5 + 28) * 1.2) = 55
- base_fare = 13 + 55 = 68
- 满60减12：68 - 12 = 56
- 85折：floor(68 * 0.85) = 57
- 附加费：20 + 5 = 25

答案：
```json
{"total_fare":81,"base_fare":68,"applied_discount":"满60减12"}
```
