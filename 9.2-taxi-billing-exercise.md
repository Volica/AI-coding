# 9.2 习题二：网约车计费系统

这一题来自 `test/texi` 文件夹，原文件名里是 `texi`，内容实际对应 taxi billing。题目的核心是处理分段计费、夜间加价、优惠券寻优和附加费作用域。

![网约车计费练习](assets/9-2-1.png)

## 题目要点

| 规则 | 要求 |
| --- | --- |
| 起步价 | 13 元，包含前 3 公里 |
| 分段里程 | 3 到 10 公里按 2.5 元/公里，10 公里以上按 3.5 元/公里 |
| 夜间加价 | 23:00 到 06:00 只对纯里程费加收 20%，并向上取整 |
| 优惠比较 | 满减券和折扣券同时存在时，选择用户支付更少的方案 |
| 附加费 | 高速费、过路费、停车费不参与折扣 |
| JSON 输出 | 只允许 `total_fare`、`base_fare`、`applied_discount` 三个字段 |

## 练习标签

```sbs-exercise
key: taxi-billing-json
title: 网约车计费 JSON 输出
kind: completion
language: python
judgeMode: testCases
description: |
  补全 calculate_taxi_bill(description)，根据一段网约车描述计算费用，并返回标准 JSON 字符串。

  JSON 只能包含三个字段：
  - total_fare：最终需支付的总金额
  - base_fare：打折前基础车费，不含附加费
  - applied_discount：实际生效的优惠策略

  计费顺序必须固定为：分段计算纯里程费 -> 夜间纯里程费加价并向上取整 -> 得到 base_fare -> 选择最优优惠 -> 叠加附加费。

  公开样例：
  | 输入 | 期望输出 |
  | --- | --- |
  | 昨晚11点半打车回家，一共跑了14公里，交了10块钱过路费，账户里有一张满40减8元的券和一张75折券 | {"total_fare":48,"base_fare":51,"applied_discount":"75折"} |
code: |
  import json
  import math
  import re

  EXPECTED_CASES = [
      {
          "input": "昨晚11点半打车回家，一共跑了14公里，交了10块钱过路费，账户里有一张满40减8元的券和一张75折券",
          "expected": {"total_fare": 48, "base_fare": 51, "applied_discount": "75折"},
      },
      {
          "input": "下午3点打车去公司，全程2.5公里，停车费5元，没有优惠券",
          "expected": {"total_fare": 18, "base_fare": 13, "applied_discount": "无"},
      },
      {
          "input": "晚上11点20分出发，打车11.2公里，没有附加费，有一张满40减10元券和一张75折券",
          "expected": {"total_fare": 30, "base_fare": 40, "applied_discount": "满40减10"},
      },
      {
          "input": "凌晨1点打车去机场，一共5公里，路桥费3元，账户里有满30减5和9折券",
          "expected": {"total_fare": 20, "base_fare": 19, "applied_discount": "9折"},
      },
      {
          "input": "夜里2点半坐网约车跨城，全程18公里，高速费20元，停车费5元，有满60减12元券和85折券",
          "expected": {"total_fare": 81, "base_fare": 68, "applied_discount": "满60减12"},
      },
  ]

  def assert_valid_json_only(raw_output):
      raw_output = raw_output.strip()
      parsed = json.loads(raw_output)

      assert isinstance(parsed, dict), "模型输出必须是 JSON 对象"
      assert set(parsed) == {"total_fare", "base_fare", "applied_discount"}, "只能输出指定三个字段"
      assert isinstance(parsed["total_fare"], (int, float)), "total_fare 必须是数字"
      assert isinstance(parsed["base_fare"], (int, float)), "base_fare 必须是数字"
      assert isinstance(parsed["applied_discount"], str), "applied_discount 必须是字符串"

      return parsed

  def calculate_taxi_bill(description):
      # BEGIN_SOLUTION
      def normalize_number(value):
          number = float(value)
          return int(number) if number.is_integer() else number

      distance_match = re.search(r"(\d+(?:\.\d+)?)公里", description)
      distance = float(distance_match.group(1)) if distance_match else 0

      mileage_fee = 0
      if distance > 3:
          mileage_fee += min(distance - 3, 7) * 2.5
      if distance > 10:
          mileage_fee += (distance - 10) * 3.5

      time_match = re.search(r"(昨晚|晚上|夜里|凌晨|下午)?(\d{1,2})点", description)
      is_night = False
      if time_match:
          period = time_match.group(1) or ""
          hour = int(time_match.group(2))
          if period in ("昨晚", "晚上") and hour < 12:
              hour += 12
          if period == "凌晨":
              hour = 0 if hour == 12 else hour
          is_night = hour >= 23 or hour < 6

      if is_night:
          mileage_fee = math.ceil(mileage_fee * 1.2)

      base_fare = normalize_number(13 + mileage_fee)

      extra_fee = 0
      fee_names = "高速费|过路费|路桥费|停车费"
      for fee_name, amount in re.findall(rf"({fee_names})(\d+(?:\.\d+)?)\s*(?:元|块钱)?", description):
          extra_fee += float(amount)
      for amount, fee_name in re.findall(rf"(\d+(?:\.\d+)?)\s*(?:元|块钱)?({fee_names})", description):
          extra_fee += float(amount)
      extra_fee = normalize_number(extra_fee)

      discounts = [("无", base_fare)]

      for threshold, discount in re.findall(r"满(\d+(?:\.\d+)?)减(\d+(?:\.\d+)?)", description):
          threshold = float(threshold)
          discount = float(discount)
          if base_fare >= threshold:
              label = f"满{normalize_number(threshold)}减{normalize_number(discount)}"
              discounts.append((label, base_fare - discount))

      for rate in re.findall(r"(\d+(?:\.\d+)?)折", description):
          rate_text = rate
          rate_value = float(rate)
          rate_multiplier = rate_value / 10 if rate_value < 10 else rate_value / 100
          discounted_fare = math.floor(base_fare * rate_multiplier)
          discounts.append((f"{rate_text}折", discounted_fare))

      def discount_rank(item):
          label, fare = item
          tie_order = 0 if label.startswith("满") else 1
          return fare, tie_order

      applied_discount, discounted_base = min(discounts, key=discount_rank)
      total_fare = normalize_number(discounted_base + extra_fee)

      result = {
          "total_fare": total_fare,
          "base_fare": base_fare,
          "applied_discount": applied_discount,
      }
      return json.dumps(result, ensure_ascii=False, separators=(",", ":"))
      # END_SOLUTION
judgeTests: |
  for index, case in enumerate(EXPECTED_CASES, start=1):
      raw_output = calculate_taxi_bill(case["input"])
      actual = assert_valid_json_only(raw_output)
      check(f"第 {index} 条用例", actual, case["expected"])
```
